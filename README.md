# Java WebSockets

Project main goal is to create simple Websocket request parser, and server.
Main source is RFC6455

- [x] Parsing HTTP Requests
- [x] Opening WebSockets handshake
- [x] Handling ping, pong and close control frame
- [x] Handling text, and binary incoming messages
- [x] Handling text, and binary responses
- [x] Handling masking, and unmasking operations on payload
